3. GitHub 연결

토큰 만들기: github.com → Settings → Developer settings → Fine-grained tokens → Repository access를 changminim.github.io 하나로 제한 → Permissions에서 Contents: Read and write만 부여. 토큰은 이 브라우저의 localStorage에만 저장됩니다. 토큰이 없으면 변경 사항이 파일로 다운로드되며, GitHub에서 presentation/locks.json을 직접 교체하면 됩니다.

4. 비밀번호 보관함 (이 브라우저에만 저장)
