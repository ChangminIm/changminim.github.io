# 아이걸음 · 09 환경 노출

2026-09-14 공개판 사용 안내. [아이걸음 예비 분석](https://changminim.com/tracker/)에서 **환경 노출**을 선택하거나, [분석 도구를 넓게 열어](https://changminim.com/tracker/atlas.html?view=1&tab=exposure) **09 환경 노출**을 선택한다. 기존 01–08 탭과 STKDE도 함께 탐색할 수 있다.

이 탭은 한 사람의 관측 시간 구간을 지도·시간 띠·숫자·환경 순서 궤적이 공유하도록 만든 환경 노출 탐색 도구다. 현재 입력은 성인 1명의 2026-09-10·11 시험 GPS와 저장된 OSM 시설·도로다. 실제 아동의 시설 이용, 섭취, 신체활동 강도, 비만 영향을 검증한 결과는 아니다.

## 추가한 보기

| 보기 | 조작과 연구상 용도 |
|---|---|
| 하루 읽기 | 관측 상태 24시간 띠, 지도, 시설 거리–시각 곡선, 네 환경 띠를 함께 읽는다. 시간 띠 드래그는 공통 시간창을 확대하고, 클릭은 원구간과 최근접 시설 근거를 연다. 짧은 인접 구간 버튼은 전후 약 5분을 확대한다. |
| 동시 환경 | 공원·운동시설 / 편의점 / 식료품·제과 / 음식점·카페의 16개 배타 조합을 시간 가중 행렬과 막대로 비교한다. 조합을 누르면 지도·띠·상세 구간을 연동한다. |
| 거리와 경계 | 반경별 인접분 곡선, 원래 이진 인접과 히스테리시스·최소 지속시간 적용 결과, 판정 변경량을 비교한다. 경계와 기기 보고 정확도가 겹치는 관측도 확인한다. |
| 같은 시각 비교 | 날짜별 관측을 같은 KST 축에 놓는다. ‘두 날짜 공통 관측 시각’은 실제 유효 구간의 교집합을 두 날짜에 똑같이 적용한다. |
| 3D와 새 방법 | **관측 시공간**, **관측과 가정 일정**, **환경 순서 궤적**을 2D/3D로 전환한다. 관측 실선과 가정 계획 점선을 구분한다. 누적 환경 궤적의 점은 원래 관측 구간과 연결된다. |
| 경로 정밀 비교 | 같은 경로의 기존 중점 근사 v1과 도형 교차 v2를 나란히 비교한다. 정밀 환경 비용으로 추가 탐색한 후보와 후보 집합 내 파레토 여부를 표시한다. |

기존 계획의 ‘관측과 기회의 시공간’과 ‘환경 순서 궤적’은 **3D와 새 방법** 안에 함께 넣었다. 정밀 경로 비교는 별도 여섯 번째 메뉴로 추가했다. 기존 합성 도시 정답 예제·기회 단절·대안과 지연·순서 서명은 08 새 방법에서 계속 사용할 수 있다.

## 먼저 해볼 세 가지

1. **9월 10일 → 거리와 경계 → 공원·운동시설.** 40m, 50m, 60m를 번갈아 고른다. 인접분이 약 239.4 → 268.0 → 423.1분으로 바뀐다. 이 자료에서는 반경 하나가 결과를 크게 바꾼다. 원래 띠와 안정화 띠를 비교하면 경계 근처 반복을 확인할 수 있다.
2. **동시 환경 → 음식점·카페만 있는 조합.** 음식점 인접 전체 11.6분 중, 다른 세 범주에 인접하지 않은 조합은 약 8.4분이다. 겹치는 인접을 범주별로 더한 값과 실제 합집합 시간을 구별할 수 있다.
3. **경로 정밀 비교 → B→C → 50m → r2.** 식품 인접은 기존 약 2.00분, 도형 교차로 계산하면 약 3.56분이다. 기존 결과를 지우지 않고 근사가 만든 차이를 직접 확인한다.

## 공통 선택과 3D 읽기

- 날짜, 기준 환경, 반경, 공유 시간창은 관측 그림에 함께 적용된다. `하루 전체·조합 해제`는 전체 시간창으로 돌아간다. 조합만 해제하면 현재 시간창은 유지한다.
- 시간 띠의 색은 인접, 회청색은 관측했지만 비인접, 사선은 미관측이다. 24시간 상태 띠에서는 원본 기록 공백, 정제 후 유효 관측 없음, 기록 범위 밖을 따로 보여준다.
- 상세 카드의 `확인할 시각`은 키보드로 입력할 수 있다. 해당 시각에 기록이 없으면 가장 가까운 유효 구간으로 연결하고 실제 구간 시각을 표시한다.
- 관측 3D는 X·Y 지역 좌표(m), Z KST 시각이다. 환경 순서 궤적은 X·Y 환경별 누적 인접분, Z 시각이다. 공백이나 조합 선택으로 제외한 구간을 건너 순서를 만들지 않는다.
- 3D의 겹친 점은 화면에서 구분하기 어려울 수 있다. 이때 시간 입력과 연결된 시간 띠로 확인한다. 2D로 바꾸거나 시점을 회전할 수도 있다.
- 가정 일정은 보행 4.8km/h, 시설 개방 08:00, 필수 일정 체류 10분을 적용한다. 출발·마감·다음 일정·최종 도착·활동 체류는 바꿀 수 있다. 필수 일정 자체가 성립하지 않으면 별도 경고한다. 표시된 완결 계획은 선언한 도로·시설 후보와 일정 가정 안에서의 결과다.
- `08 새 방법에서 조건별 진단` 또는 기존 연구 도구 연결은 날짜와 적용 가능한 조건을 전달한다. `이전 탐색으로 돌아가기`는 출발 화면의 선택을 복원한다.
- 반경 반응·날짜 비교는 시간창 전체를 비교한다. 조합 선택이 있을 때는 상단 선택 요약과 범위가 다르다는 설명이 표시된다. 경로 비교는 관측 시간창과 독립된 보행 시나리오다.

## 자료와 계산 기준

사람→날짜→파일→세그먼트→연속 관측을 구분한 **7,054개 시간 구간**을 만들었다. 유효한 두 점 사이 시간은 시각 중간에서 절반씩 나눈다. 60초를 넘는 공백은 연결하지 않는다. 시간창 경계에 걸친 구간은 해당 부분의 분만 센다. 같은 사람·날짜의 동시 세션이 겹치면 중복 계산을 중단한다.

두 날짜의 공통 관측 시각은 **17.2861분**이다. 시간대를 맞춰도 지역·활동 목적·수단은 같아지지 않으므로 날짜의 건강 순위를 만들지 않는다. 실제 아동 연구에 적용하려면 시설 현장 확인과 이용·동행·등하교 등 맥락 자료를 결합해야 한다.

정밀 경로는 저장된 선형 도로와 시설 도형의 반경 영역이 교차하는 부분을 계산한다. 같은 범주 시설과 식품 3종의 중첩은 합쳐 한 번만 센다. 도로 길이 비율을 80m/분 보행 시간으로 변환한다. 접점 연결 시간은 따로 표시하고 환경 계산에서는 제외한다. **139개 경로·반경 조합, 7,816개 교차 구간**을 포함한다. 도형 교차의 정밀화가 지도 오차·시설 누락·출입 가능성을 해결하는 것은 아니다.

## 저장과 재현

- **결과 CSV**: 현재 모듈의 표와 조건. 거리와 경계에서는 원래 인접분·안정화 인접분·변경분·안정화 반경도 함께 저장한다.
- **조건·결과 JSON**: 조건과 원구간·환경 순서·가정 계획 등 세부 결과. 경로 모듈에서는 선택 경로와 도로 교차 구간을 저장한다.
- **그림 SVG / 지도 PNG**: 해당 그림을 저장한다. 좁은 화면에서는 그래프 내부를 좌우로 스크롤하며, SVG로 전체 축을 저장할 수 있다.
- **카드 ⋯ → View data source**: 원자료 선택, 자료 미리보기, 계산 과정과 가정 확인.

원본 개발 자료에서 **1,719개 계산 검증 통과**, 기존 23개 데이터 정의·행 해시 보존을 확인했다. 50m 공주 경로 42건은 별도의 최대 0.5m 간격 거리 판정과 대조했으며 최대 범주 차이는 약 **0.01012분(0.61초)**이었다. 두 날짜, 선택·드래그·탭 이동·3D·빈 시간창·저장·390px 배치를 표본 조작했다. 모든 기기·브라우저 조합이나 현장 노출 타당성을 검증한 것은 아니다.
